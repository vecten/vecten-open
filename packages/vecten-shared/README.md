# vecten-shared

The runtime contracts shared by the Vecten Open CLI, platform and MCP packages: configuration, output, versions, the semantic-model loader.

This is an internal distribution of [Vecten Open](https://github.com/vecten/vecten-open); install the CLI, `vecten`, which
brings what it needs, and read the [documentation](https://github.com/vecten/vecten-open/blob/main/docs/README.md). The four
distributions are released together at one version.
